# Geocomputing Centre

**The UNIL FGSE platform for geocomputing, data science and machine learning**

[Centre on unil.ch](https://www.unil.ch/fgse/en/home/menuinst/recherche/geocomputing-centre.html) · [Data, software & dev hub](https://unil-sgc.github.io) · [sgc@unil.ch](mailto:sgc@unil.ch)

</div>

The Geocomputing Centre brings together researchers of the Faculty of Geosciences and Environment (FGSE) at the University of Lausanne who develop or use computational methods, from numerical modelling and high-performance computing to data science and machine learning.

## 🧭 Data, software and dev hub

This organisation hosts the Centre's **[data, software and dev hub](https://unil-sgc.github.io)**, the practical side of geocomputing at FGSE for developers and data users. It is plain Markdown on GitHub: every page has an *Edit this page* link, and pull requests get a live preview.
